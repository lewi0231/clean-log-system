# Completed Jobs User Stories

This directory contains user stories related to the completed jobs functionality in the dashboard.

## User Stories

- [001: Completed Jobs Display and Audit Trail](./001-completed-jobs-display-and-audit.md) - Field display, audit trail, and location restrictions for completed jobs

## Overview

Completed jobs represent jobs that have been finished by workers. Admins can view these jobs, see their submission data, and create/edit jobs manually for testing or corrections.
