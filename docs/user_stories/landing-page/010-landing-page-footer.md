# User Story 010: Landing Page Footer

## Overview

The footer provides important links, legal information, and additional resources. It should be comprehensive but organized, helping users find what they need while maintaining trust and credibility.

## User Story

**As a** visitor to the RivetUp website  
**I want to** find important links, legal information, and contact details  
**So that** I can access resources, understand policies, and contact support when needed

## Acceptance Criteria

### 1. Footer Structure
- Organized into columns (3-4 columns on desktop)
- Stacked on mobile
- Clean, scannable layout
- Consistent with brand style

### 2. Footer Sections

#### A. Product Links
- Features
- Pricing
- Mobile App
- Integrations (if applicable)
- Roadmap (optional)

#### B. Resources
- Help Center / Documentation
- Blog (if applicable)
- Case Studies
- API Documentation (if applicable)
- Video Tutorials

#### C. Company
- About Us
- Careers (if applicable)
- Contact
- Press Kit (optional)
- Partners (optional)

#### D. Legal & Policies
- Privacy Policy
- Terms of Service
- Cookie Policy
- Security
- Compliance (if applicable)

### 3. Contact Information
- Email: support@rivetup.com (or relevant email)
- Phone: (if applicable)
- Address: (if applicable)
- Social Media Links: (if applicable)

### 4. Social Media Links (Optional)
- LinkedIn
- Twitter/X
- Facebook
- Instagram
- YouTube (if applicable)
- Icons with links, opens in new tab

### 5. Newsletter Signup (Optional)
- Email input field
- "Subscribe" button
- Brief description: "Get tips and updates"
- Privacy note: "We respect your privacy"

### 6. Trust Badges
- Security certifications
- Industry memberships
- Awards (if applicable)
- "Australian-owned" or location-specific badges

### 7. Copyright and Legal
- Copyright notice: "© 2026 RivetUp. All rights reserved."
- Legal links (Privacy, Terms)
- Last updated date (optional)

### 8. Mobile Responsiveness
- Footer stacks vertically on mobile
- All links easily tappable
- Readable text size
- Collapsible sections (optional, if many links)

## Design Principles

1. **Organization**: Logical grouping of links
2. **Scannable**: Easy to find what you need
3. **Comprehensive**: All important links included
4. **Trustworthy**: Legal links, contact info visible
5. **Consistent**: Matches overall site design

## Content Guidelines

### Link Labels
- Clear, descriptive labels
- Use common terms
- Group related links together
- Don't use abbreviations unless widely understood

### Contact Information
- Use real contact information
- Include response time expectations (if applicable)
- Multiple contact methods (email, phone, chat)

### Legal Links
- Must include: Privacy Policy, Terms of Service
- Should include: Cookie Policy (if using cookies)
- Optional: Refund Policy, Acceptable Use Policy

## Technical Requirements

- Responsive design (stacks on mobile)
- All links functional and tested
- External links open in new tab
- Fast loading (don't block page render)
- Accessible: Keyboard navigation, screen reader friendly

## Footer Layout Example

```
[Product]          [Resources]        [Company]          [Legal]
Features          Help Center        About Us          Privacy Policy
Pricing           Blog               Contact            Terms of Service
Mobile App        Case Studies       Careers            Cookie Policy
Integrations      API Docs           Press              Security

[Social Media Icons]          [Newsletter Signup]

[Trust Badges]

© 2026 RivetUp. All rights reserved.
```
