# User Story 002: Landing Page Features Section

## Overview

The features section showcases RivetUp's core capabilities in a way that resonates with small service businesses. It should highlight the key differentiators and address specific pain points of tradespeople and car detailers.

## User Story

**As a** small business owner evaluating RivetUp  
**I want to** see the key features and understand how they solve my specific business problems  
**So that** I can assess if RivetUp meets my needs before signing up

## Acceptance Criteria

### 1. Feature Organization
- Features grouped into logical categories (3-6 main feature groups)
- Each feature group has a clear title and icon/illustration
- Features presented in order of importance/value to target audience
- Maximum 6-8 features total to avoid cognitive overload

### 2. Core Features to Highlight

#### A. Mobile Job Management
- **Title**: "Mobile Job Tracking"
- **Description**: "Your workers complete jobs on their phones with custom forms. No more paper, no more lost data."
- **Visual**: Mobile app screenshot showing job form
- **Benefit**: "Jobs sync instantly to your dashboard"

#### B. Automated Invoicing
- **Title**: "Automated Invoicing"
- **Description**: "Invoices generated automatically when jobs are completed. Send to customers with payment links included."
- **Visual**: Invoice preview or dashboard showing invoice list
- **Benefit**: "Get paid faster with automated payment links"

#### C. Flexible Pricing Rules
- **Title**: "Custom Pricing Rules"
- **Description**: "Set pricing by unit, location, service type, or flat rate. Perfect for complex pricing structures."
- **Visual**: Pricing configuration interface
- **Benefit**: "Price jobs exactly how your business works"

#### D. Worker Management
- **Title**: "Worker Management"
- **Description**: "Add workers, track their jobs, manage payments, and monitor performance ratings."
- **Visual**: Worker dashboard or list view
- **Benefit**: "Keep your team organized and accountable"

#### E. Customer Locations
- **Title**: "Location Management"
- **Description**: "Manage fixed customer locations (like car yards) with location-specific pricing and requirements."
- **Visual**: Map or location list view
- **Benefit**: "Perfect for businesses with recurring customers"

#### F. Real-Time Sync
- **Title**: "Real-Time Updates"
- **Description**: "Jobs completed in the field appear instantly in your dashboard. No delays, no confusion."
- **Visual**: Dashboard showing real-time updates
- **Benefit**: "Always know what's happening with your business"

### 3. Feature Presentation Format
- **Option A: Grid Layout** (3 columns on desktop, 1 on mobile)
  - Icon/illustration at top
  - Feature title
  - 2-3 sentence description
  - Optional: "Learn more" link

- **Option B: Alternating Layout** (feature left, visual right, then reverse)
  - More space for detailed explanations
  - Better for storytelling
  - More engaging visual flow

- **Option C: Tabbed Interface** (for many features)
  - Reduces cognitive load
  - Allows deeper exploration
  - Good for feature-rich products

### 4. Visual Elements
- Screenshots of actual product (not generic stock photos)
- Animated GIFs showing feature in action (optional)
- Icons that match brand style
- Consistent visual style across all features

### 5. Benefit-Focused Copy
- Each feature description starts with the benefit, not the feature
- Uses "you" language (not "we" or "our product")
- Addresses specific pain points:
  - "Stop chasing paperwork"
  - "Get paid faster"
  - "No more manual calculations"
  - "Track everything in real-time"

### 6. Industry-Specific Examples
- Car detailing example: "Track car size, service type, and location pricing"
- Tradesperson example: "Price jobs by hours, materials, and location"
- Cleaning service example: "Manage recurring jobs at fixed locations"

## Design Principles

1. **Scannable**: Users can quickly scan and understand features
2. **Visual**: Each feature has accompanying visual
3. **Benefit-First**: Lead with what users gain, not what the feature is
4. **Specific**: Use concrete examples, not vague promises
5. **Credible**: Show actual product, not generic illustrations

## Content Structure

### Feature Card Template
```
[Icon/Visual]
[Feature Title]
[2-3 sentence benefit-focused description]
[Optional: "See how it works" link]
```

### Example Feature Card

**Mobile Job Tracking**
Your workers complete jobs on their phones with custom forms tailored to your business. Whether it's car details, service notes, or time tracking, everything syncs instantly to your dashboard. No more lost paperwork or delayed updates.

## Technical Requirements

- Lazy load feature images below the fold
- Smooth scroll animations when features come into view
- Mobile-optimized images (responsive srcset)
- Accessible: Alt text for all images, keyboard navigation

## Success Metrics

- Scroll depth to features section
- Time spent in features section
- Click-through on "Learn more" links (if present)
- Conversion rate from features section to signup
