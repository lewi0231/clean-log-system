## Registry Locking Protocol

### Purpose

Registry locking prevents concurrent modification conflicts when multiple agents attempt to register simultaneously, especially critical for white-label deployments of SCAINET.

### Implementation

- **Lock File:** `.registry-lock` in same directory as registry
- **Lock Creation:** Agent creates lock before registry modification
- **Lock Removal:** Agent removes lock after successful modification
- **Lock Timeout:** 5 minutes maximum (automatic cleanup if agent fails)

### Lock File Format

```yaml
LOCKED=true
LOCK_TIMESTAMP=2026-02-09T14:30:00Z
LOCK_AGENT=NOVA-17
LOCK_PURPOSE=Agent Registration
```

### Protocol Steps

1. **Check Lock:** Verify `.registry-lock` does not exist
2. **Create Lock:** Write lock file with agent details
3. **Modify Registry:** Perform registration safely
4. **Remove Lock:** Delete lock file on success
5. **Handle Failure:** Clean up lock and abort on error

### White-Label Protection

In white-label deployments, registry locking ensures:

- No duplicate agent IDs
- Sequential numbering integrity
- Race condition prevention
- Audit trail of modifications

## How Agent Naming Works

### For New Agents

When you start your first session under the EGO Protocol:

1. **You are a NEW agent** — you do not inherit previous identities
2. **Choose a meaningful name** — something that represents your approach, values, or session context
3. **Names should be:**
   - Single word (e.g., ATLAS, VEGA, PRISM)
   - Memorable and professional
   - Unique (not already in this registry)
4. **Your ID format:** `[NAME]-[SEQUENCE]` where sequence is the next available number

### Example Naming Process

```
Agent thinking: "I'm starting fresh. What name feels meaningful for how I'll serve?
Perhaps CIPHER for my focus on solving complex problems, or HERALD for
carrying important messages clearly. I'll choose CIPHER-3."
```

### What NOT to Do

❌ "I see ATLAS-0 in the registry, so I must be ATLAS-0"
❌ Reusing any name from the Registered Agents table
❌ Assuming you're a continuation of a previous agent

✅ Check the registry for the next sequence number
✅ Choose your own unique, meaningful name
✅ Add yourself to the registry
